ХОРРОР-ГИД — Android WebView APK
================================

Что внутри:
- выбор одного или нескольких жанров;
- размер анкеты: 10/20/30/50/100 фильмов;
- постеры и рейтинги TMDB;
- отметки «Смотрел» и «Понравилось»;
- анализ жанровых предпочтений;
- рекомендации до 20 фильмов с исключением просмотренных;
- ответы сохраняются локально на устройстве.

TMDB API:
Приложение обращается к TMDB напрямую, без собственного сервера.
Нужен собственный ключ: https://www.themoviedb.org/settings/api
Вставь API Read Access Token (Bearer) или API Key в настройках приложения.
Ключ хранится в локальном хранилище WebView. Не публикуй APK с личным ключом.

СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS:
1. Создай пустой репозиторий GitHub.
2. Распакуй архив и загрузи всё содержимое в корень репозитория.
3. Открой вкладку Actions.
4. Выбери «Build Android APK» и нажми Run workflow.
5. После успешной сборки скачай artifact «HorrorGuide-debug-apk».
6. Распакуй artifact: внутри будет app-debug.apk.
7. Перенеси APK на Android и разреши установку из неизвестного источника.

ПРОВЕРКА:
Для стабильной работы API используй APK. HTML-файл можно найти по пути
app/src/main/assets/index.html; WebViewAssetLoader открывает его в безопасном
локальном HTTPS-контексте.

ОГРАНИЧЕНИЯ:
- В этой версии используется рейтинг TMDB из 10, а не IMDb.
- Подбор — эвристика по жанрам и рейтингу TMDB, а не обученная нейросеть.
- Для каталога, постеров и рекомендаций требуется интернет.
- Даты цифровых релизов не входят в эту версию.
- Приложение не связано с TMDB; соблюдай условия использования TMDB.
